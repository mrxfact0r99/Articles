The Bug Discovery 🐛

The bug was simple yet effective. I was hunting on the site login.target.com and decided to use paramspider to find any interesting parameters.

paramspider -d login.target.com

I came across a particularly interesting URL endpoint: /status. When I visited this endpoint, I saw some server information. However, I noticed a parameter: ?full=FUZZ.

I tried several inputs for the full parameter, but nothing worked at first. Then, a thought crossed my mind. 🤔 I changed full=false—no change. But then I switched it to full=true, and BOOM! 💥 I was able to access the full server status and additional information about the running server.

Tip 💡

Add /status and /status?full=true to your wordlist for future tests. It might come in handy!

Bug Reporting 📝
